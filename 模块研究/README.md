## 不强行归入工厂

道路保洁、公交运营、道路信号、农业、游戏与通用创作题不因共享规划/AI方法就纳入制造主链；保留原研究位置。市政排水和港口作业也不自动作为本次厂内模块。

## 使用方式

先读主题总结的工作链、输出和接入责任，再由原定义查看专业细节与真实阅读范围。新增代码实现仍从软件工程/docs/04_开发与验收/tasks.json进入；本目录不是插件加载目录。
