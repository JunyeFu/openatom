# 仓库导航

## 使用与开发

| 路径 | 用途 |
| --- | --- |
| `README.md` | 产品展示与下载入口 |
| `docs/` | 当前开发、状态、仓库导航及首页图片 |
| `软件工程/apps/` | 桌面应用、云服务及MCP入口 |
| `软件工程/packages/` | 领域、命令、仿真、报告与表现等共享模块 |
| `软件工程/modules/` | 设备、模板、表现素材及其他业务定义 |
| `软件工程/resources/` | 应用与演示使用的运行资源 |
| `软件工程/integrations/` | Agent和外部软件连接入口 |
| `软件工程/tests/` | 测试 |
| `软件工程/scenarios/`、`软件工程/tools/` | 业务场景和开发工具 |
| `软件工程/docs/` | 需求、架构、契约与分阶段交付资料 |

## 研究与历史设计

`模块研究/`、`研究资料/`、`设计预览/`保留研究过程和设计来源。历史AI预览不是当前产品截图，历史日期和未实现声明只代表当时阶段；当前运行能力见产品首页，开发状态见[进度](STATUS.md)。

## 维护约定

- 产品实现继续放在 `软件工程/`，保留代码与资源路径。
- 面向使用者的运行包、示例与指南放在正式 Releases；源码获取使用 Git + Git LFS。
- 首页截图集中在 `docs/assets/`；本次三张截图来自本地作品介绍的实际应用画面。
- 临时缓存、新的本机运行输出不作为源码提交；已有研究、资源和历史证据保留原路径。
- 根目录 `LICENSE` / `NOTICE` 提供许可入口，资源自身许可继续保留。
