# 工厂方案彩排：视图预览

[打开图集](图集.html) · [交互规格](当前交互规格.md) · [对象设计](多层视图与对象设计.md) · [实现阶段与模块目录](../软件工程/README.md)

观察层次有设备操作、单线、整厂与多厂；常态画布只有流水线和多厂房两个。设备详情靠单击进入；滚轮改变同一厂房画布的详细、简化、区域三档表现。

清单目标：12种设备/资源对象、2种人工任务、3条独立产线及1张整体移动、2张整厂精细度、2张同基地/跨基地供应网络。所有图片为AI生成的界面设计预览，不代表可运行软件或工业现场结果；最终选用文件由图片记录.json确定，原图和旧修订保留但不打包。

动图/模型导入及社区模块包的行为设计见软件工程/docs/03_架构与契约/模块设计.md。人员、AGV、手推车是移动资源；固定设备只在方案编辑时搬移。

准备视图.py同步提示词；整理图集.py检查图片存在并制作图集与压缩包，不启动产品实现。

## 目标驱动建厂的现行交互

在现有两画布工程中提供外部Agent目标任务面板：产品/日产/场地→模板候选/来源与缺项→九类填充、设备与连线逐步出现→静态布局检查→运行时物品流动、等待与合格接受量→修正比较→报告/可编辑工程。用户可单击编辑生成对象；缩放仍只改三档LOD。已有22张AI图保留原生成记录，仅作风格和既有过程参考，尚未完整展示SF-17；新增视图要求见[现行需求](../软件工程/docs/03_架构与契约/目标驱动厂房生成.md)。
