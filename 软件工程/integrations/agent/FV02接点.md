# Agent 消费与候选交付接点

Agent 通过 `superfactory-mcp-bridge.exe` 的 stdio MCP 连接当前桌面的同一个 Host。`stdio_client.py` 只处理子进程、协议关联与有限等待；业务由原 `workflow.py::ExecutionWorkflow`、Commands 和 Engine 执行。

|接点|实际输入与返回|权限和拒绝边界|
|---|---|---|
|连接|当前 Host 给出的管道与实例 ID；真实 OS peer 等待 Native 授权|端点本身不是权限；新连接不继承旧调用者、目录令牌或任务权限|
|发现|MCP `tools/list`；workspace `describe_capabilities`；`get_context` 的实际 context|只消费真实广告的工具；Gateway 私有操作不向普通 Agent 开放；不能固定工具数量|
|读取|当前工程对象、冻结 Run、执行配置、原会话/epoch 的快照和输入|工程与作用域由 Host 核验；旧 Run 只读，读取不推进生产时钟|
|修改|完整 canonical `apply_commands` 和原 `base_revision`|Host 核验操作、对象字段和累计创建额度；批次越权整体拒绝；修订冲突不覆盖原稿|
|准备|H08 原工程/方案修订、实际候选绑定、明确选择的完整 policy → H01 原 Task|成功只表示 prepared；准备和 run 分开；不能用预测 Run 代替生产执行|
|执行控制|H02 latest、Host-origin/current-owner access、实际允许动作、原 expected R → H03 ack|操作分别授权；RevisionConflict 返回刷新供重新决策；未知回执不重投|
|任务|原操作、request ID、Task ID/kind/scope/input revision → `get_task`|admission 不是完成；failed/cancelled 保持真实终态；共享一个旧 Task 不授权其他任务或旧文件令牌|
|数据与报告|原 identity/R/F/T、筛选和用途明确的 SelectedFileRef|H10/H11 导出全部原筛选；用途分别为 `export_execution_report` / `export_cloud_data`；不收裸路径，不猜令牌|
|保存与重开|真实当前连接的 `save_project` 目录令牌、原修订 → 原保存 Task；新进程打开保存件|保存完成才有可读回交付；重连/重启边界分开；新进程不重新创建旧执行|

版本分别为：产品 **2.0.1**，canonical API **0.1**，工程格式 **1.0**，执行契约 **sf.execution/2.0-draft11**，内部 IPC **1**。MCP 协议由初始化协商，与这些版本独立。stdio 是逐行 JSON-RPC；Windows Host 管道使用既有长度分帧，不能混用。

## 有限等待和恢复

断线、超时、非协议 stdout 或响应关联不符会结束当前 stdio 连接；原完整业务请求保留，客户端不重投。已被 Host 接纳的任务不因桥 EOF 自动取消。H09 仅查询原调用者的原请求；新连接需要重新授权，已知原 Task ID 时还需明确共享该确切 Task。不知道原 Task ID 且原请求查不到时保持未知，不推断“未执行”。控制 H03 当前没有对应请求登记恢复结果，不能用一张新快照猜原控制是否受理。

联验命令、停止和恢复见 [FV02 联验入口](../../tools/cloud/FV02联验入口.md)。业务输入、数量、执行、产出和运输应从真实快照及保存件核对；退出码或一次读取不能代替这些观察。

## 候选资源闭包

- 候选必须同时包含本次源码对应的 `superfactory.exe` 和 `superfactory-mcp-bridge.exe`。制包入口不再静默省略 bridge；可执行文件头检查只判断输入基本类型，不证明两者来自同一提交。源码/构建来源仍须单独核对。
- 沿用 Tauri 资源映射和 `package_v2.py` 的实际启动模块/FileRef 闭包。保留模块的确切版本、依赖、素材、报告字体及许可；未下载实体内容的 Git LFS 指针不得作为资源交付。
- 设备运行资源沿用受信任的 `v2-devices` Python 安装与四个原脚本，不携带账号、私有配置、SDK journal 或测试数据库。系统 WebView2 和 Windows x64 前提沿用现有操作指南。
- 下载、解压、正常入口启动及实际业务短流程需独立验证。复制、打 ZIP、文件清单或协议单元检查均不能代替 Native 或业务验收。
