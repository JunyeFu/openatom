# packages/simulation

统一时钟、输入消耗、产出、等待、齐套与资源占用。P1实现。

工序开工取得物品与资源；完成后提交一次结果，输出受阻保留待交付状态。跨厂运输分别处理预留装载、发出、抵达、接收与资源返程；运输保持货物ID，包装保留内容物身份。P1/P2应运行两厂房A/B场景核对声明的关键事件，不把手算预期作为实际结果。

## 现行目标生成与开放主线

目标生成后的工程按共同物料/资源/日历规则实际运行；接受量与等待来自RunId。规模下界和目标都不替代执行，有限反馈修改输入再跑新方案。
