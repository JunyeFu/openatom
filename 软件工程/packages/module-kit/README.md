# packages/module-kit

模块清单解析、参数编辑、导入与能力绑定。P3实现。

设备时间轴、类型化标签、人工／Agent草稿命令共用这一入口。拟议能力清单见device-editor-capabilities.design.json；状态均为设计，不是已注册接口。输入包校验放在共同导入边界，标签只能绑定声明字段／操作；原生部件数据交presentation渲染，生产规则交simulation。

作者保存、实例采用与版本升级按docs/02_交互设计/自定义设备创作与采用.md执行；显式列变化，不改库中其他实例或正在执行的方案。时间轴既支持现有固定周期，也按实际阶段绑定多阶段表现；运行等待姿态来自规则上下文，不由图片选项决定物品状态。

九类导入按[类别协议](../../docs/03_架构与契约/九类模块清单与消费者.md)与[登记设计](category-contracts.design.json)分派载荷。物品进入类型表，离散资源进入容量/日历与角色绑定，任务进入目标与前置，工艺规则进入显式端口/角色绑定，专业模块进入成果/提供者绑定，素材进入表现绑定。服务资源和其他专业声明可保存/编辑，实际服务执行及非纸包装专业内核后置。设备、运输和模板保留现有字段。所有定义不保存当前库存、占用者或实际执行结果。

设备内联behavior与operation_ref选择一处，采用时显示映射及变化。生成类别样例脚本只编写设计文件；[采用预期与S03-03边界复核](../../scenarios/九类模块采用/README.md)检查声明、范围及有限推导，尚未实现共同加载器。模板新建工程显式选择自建种子，采用到已有工程默认不带库存/订单；二者均不恢复样例运行结果。
