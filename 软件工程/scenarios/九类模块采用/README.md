# 九类声明与跨类别采用

`python 检查分类采用.py`检查登记中的共同字段、实际载荷、文件引用及跨类别绑定，再输出[有限采用预期](expected-category-adoption.design.json)。这是设计文件一致性检查，不是注册器、软件导入或生产运行。

设备示例明确选择独立齐套规则；shell/pcb/fastener角色对应实际端口，资源assembler对应同一个R1。输入2壳体、1PCB、4螺钉的声明配方只能形成1个装配体，原输入保存组成而不重新可领。独立媒体只绑定部分锚点，未绑定端口可在属性表待补，不篡改配方。

准备任务设置目标的ready，不生产板件。服务源14kW是声明容量，两个各6kW阶段在无背景时合计12kW；不能读成14件库存或已经用14kW。专业提供者available_modes为空，不从intended_modes推成功结果。

原目录/公共清单例均是design。实际实例化、别名映射、工具与GUI效果由P0/P3实现后验证。主规则见[九类协议](../../docs/03_架构与契约/九类模块清单与消费者.md)。
