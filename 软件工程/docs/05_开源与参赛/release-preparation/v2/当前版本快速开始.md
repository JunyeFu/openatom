# 超级工厂 v2.0.1 使用说明

Windows 11 x64，需已安装WebView2。完整解压 SuperFactory-2.0.1-Windows-x64.zip，双击 superfactory.exe。保留同目录的 modules、report-resources、v2-devices 等运行资源。

## 创建并运行工厂

1. 从模板新建工程，选择“纸包装多产品工厂 · 92台设备”。
2. 点击“使用模板演示配置”，查看创建预览，再点击“创建模板工厂”。
3. 选择“纸包装演示生产”并运行方案，在全厂、流水线及物品跟随视图查看结果。
4. 使用“文件 → 保存工程…”保存；新进程通过“文件 → 打开工程目录…”恢复工程和运行记录。

本地模板包含92台设备、69个订单、162次制造和273趟运输。订单交付数量合计167，包含不同产品及搬运服务。

## 打开示例工厂

可选下载 SuperFactory-2.0.1-Example-Factory.zip，解压后通过“文件 → 打开工程目录…”选择其中的“纸箱产运演示”目录。

该工程保留完整92设备厂房、本地整厂运行记录和真实云执行历史。点击“云端生产 → 执行”，选择“已保存记录1”，向下滚动，点击“回看执行画布与时间轴”；“对象类别”可选择“运输记录”。查看已保存的只读历史不需要云凭据。

历史产运案例实际完成1件纸箱产出、3趟运输、15条已派命令并正常停止。原目标2件，在首件交付后主动停止，不能称为全部订单完成。93端点整厂全部订单、长时间性能与大历史归档仍待验。

## 云端实时生产

实时云生产和数据查询需要部署者提供的私有连接文件。在“设备”页导入连接，保存工程并重新启动应用。公开包不包含令牌、账户配置或数据库密码。公网API地址不是网页前端。

打开大工程或运行方案时，请等待底部处理状态结束后继续操作。

## 运行资源及许可

superfactory.exe 为桌面程序，superfactory-mcp-bridge.exe 为 Agent/MCP 接入程序。模型、模板、字体及设备运行时与程序一并提供。许可见 LICENSE、NOTICE 及各资源许可文件。包内不含源码仓库、构建缓存、私有连接、设备日志、提交用PDF或视频。
