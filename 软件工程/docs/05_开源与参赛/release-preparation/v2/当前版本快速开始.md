# 超级工厂 v2.0.1 开始使用

完整解压后，双击 superfactory.exe 启动应用；双击同目录的“操作指南.html”阅读完整的基础与进阶指南，也可查看“操作指南.md”。

运行环境：Windows 11 x64，已安装 Microsoft Edge WebView2 Runtime。主程序、设备模型、字体和设备运行资源需要保留在同一解压目录中。

## 第一次使用

1. 在软件启动页点击“从模板开始”，填写工程名称并点击“创建”。
2. 在模板库中选择“纸包装多产品工厂 · 92台设备”，点击“使用模板演示配置”。
3. 手动填写“工厂前缀”（例如“演示工厂”）与“方案名称”（例如“纸包装演示生产”）。
4. 点击“预览创建对象”，等待预览出现，再点击“创建模板工厂”。
5. 确认顶部“当前方案”已选中刚创建的方案，点击“3 运行方案”。
6. 通过时间轴回看生产过程，点击“4 查看产量与等待”核对结果。
7. 通过“文件 → 保存工程…”保存，下一次选择“文件 → 打开工程目录…”重新打开。

## 三个启动入口

- 展示任务：打开已经下载并解压的示例工程。选择内部“纸箱产运演示”目录，并在预览中点击“确认打开”。
- 从模板开始：使用软件内置模板创建工厂，不需要另行下载示例工程。未打开工程时先填写工程名称；已有空工程时沿用当前工程。
- 空工程：创建空白工程，自行添加厂房、设备和生产方案。

## 本地与云端

模板仿真和已保存示例记录可离线使用。实时云端生产和云端数据查询需要管理员提供连接文件，具体步骤见完整操作指南。软件与资源许可见 LICENSE、NOTICE 及各资源许可文件。
