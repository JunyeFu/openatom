# 超级工厂 2.0.1 快速开始

本轮支持本地纸包装整厂，以及四设备双工序的软件设备云演示。两者分别运行；93端点整厂云扩展仍待后续完成。

## 本地整厂

1. 在 Windows 11 x64 上解压整个运行包，保留同目录的 `modules`、`report-resources` 和 `v2-devices`。系统需要 WebView2；启动 `superfactory.exe`。
2. 从模板开始创建工程，选择“纸包装多产品工厂 · 92台设备”，点击“使用模板演示配置”。查看创建预览，再点击“创建模板工厂”。
3. 选择“纸包装演示生产”，运行方案。查看全厂、流水线、物品跟随与接受结果；观察时间只改变回看位置。
4. 通过“文件 → 保存工程…”选择新目录。重开该目录可继续查看原工程和 Run。

1.7.1模板有69个订单、162次制造和273趟运输；各类订单交付数量合计167，包含不同产品及搬运服务，不能称为167件同类产品。

## 云端生产

云功能需要实际部署的 HTTPS 服务、PostgreSQL，以及部署者为当前工程签发的连接文件。连接文件、设备身份和令牌不随公开运行包提供。

在“云端生产 → 设备”导入连接文件，按提示重新启动客户端。部署者提供的双工序四设备示例目标为12件、单位piece，停止新派工时间240秒，设备状态有效期5秒。选择四台设备后“准备生产”，准备成功再“启动”。

维护演示在设备页操作“模拟设备维护”和“恢复模拟设备”。以设备观测、实际接单事件和最终接受量判断改派；在途命令会继续核对。当前已验证24条命令对应12件产出，指令条数不等于产品数量。

数据页支持筛选、固定结果和全量导出；执行页支持来源回看和生产报告。缺少可比条件的指标显示未知。生产结清后保存，新进程读取的是只读历史，再生产需要准备新会话。

云示例、模型准备与连接格式见源码中的 `tools/v2-demo/prepare_multistage.py`、`tools/v2-demo/src/multistage.rs`、`tools/cloud/sealos/README.md`。导入凭据只在本机 Native 保管，不交给网页或 Agent，也不要写进 Git。

## 包内内容

`superfactory.exe` 是桌面程序，`superfactory-mcp-bridge.exe` 是 Agent/MCP 接入程序；`modules` 为精确模型、模板及素材，`report-resources` 为报告字体及许可，`v2-devices` 为可信软件设备运行时。资源闭包和文件体积见 `V2_RESOURCE_CLOSURE.json`、`V2_PORTABLE.json`。

本地厂房仿真可独立运行；云执行和数据读取需要网络及部署权限。本轮未进行物理断网或全新操作系统测试。运行包不包含源码历史、构建缓存、私有连接、设备journal、PDF文稿或视频材料。
