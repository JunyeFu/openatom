# 超级工厂 2.0.1 演示版：开始使用

完整解压 Windows x64 运行包后，双击 superfactory.exe。需要 Windows 11 x64 和 WebView2；保留 modules、report-resources、v2-devices 等目录。

## 本地整厂演示

1. 从模板开始创建工程，选择“纸包装多产品工厂 · 92台设备”。
2. 点击“使用模板演示配置”，检查预览，再点击“创建模板工厂”。
3. 选择“纸包装演示生产”并运行方案，在全厂、流水线和物品跟随视图查看预测结果。
4. “文件 → 保存工程…”保存到新目录；“打开工程目录…”可恢复原工程和 Run。

模板含92台设备、69个订单、162次制造和273趟运输。订单交付数量合计167，包含不同产品及搬运服务。

## 已保存的真实生产案例

从同一 Release 另外下载并解压 Paper-Carton-Project.zip，通过“文件 → 打开工程目录…”打开其中的“纸箱产运演示”目录。

该案例保留92设备厂房、原整厂预测 Run，以及纸箱开箱机与厂内转运车的真实云执行历史：1件产品产出、3趟运输、15条已派命令全部收尾，停止派工后正常清理并保存。目标原为2件，本次在首件交付后主动停止，不能称为全部订单完成。

新进程读取已保存的历史时为只读。实时云生产和云数据查询需要部署者签发的私有连接文件；公开包不提供令牌、账户或数据库密码。服务的 HTTPS 地址是 API，并非网页前端。

已有四设备双工序示例另有12件产出证据；93端点完整整厂全部订单、长时间性能及大历史归档仍待验，不能由本次有限案例推定通过。

## 包内内容

superfactory.exe 为桌面程序，superfactory-mcp-bridge.exe 为 Agent/MCP 接入程序，modules 为模型、模板和素材，report-resources 为字体及许可，v2-devices 为软件设备运行时。许可见 LICENSE、NOTICE 及资源各自许可。包内不含源码、构建缓存、私有配置、设备日志、提交用 PDF 或视频。
