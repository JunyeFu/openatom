超级工厂 v2.0.1 操作指南

从创建第一座工厂，到调整生产方案与查看云端记录。

基础操作、本地进阶练习和示例历史回看都可离线完成，无需云账户。首次体验建议先完成第二部分，再尝试订单调整与方案比较；实时云端生产的连接文件与设备服务配置见第四部分。

下载应用与示例工程 · 准备与入口 · 基础操作 · 进阶操作 · 云端功能 · 常见问题

一、准备与入口

1. 下载和启动

运行环境为 Windows 11 x64，并需安装 Microsoft Edge WebView2 Runtime。下载 SuperFactory-2.0.1-Windows-x64.zip，完整解压到本地文件夹，再双击其中的 superfactory.exe。

运行包内附有“操作指南.html”和“操作指南.md”。双击“操作指南.html”即可用浏览器离线阅读本文。如果系统提示缺少 WebView2 Runtime，可从微软官方下载页选择 Evergreen Standalone Installer 的 x64 版本安装，然后重新启动超级工厂。

请保留解压目录中的全部文件。设备模型、字体和运行资源都由主程序从该目录读取，不要只把一个 exe 文件单独移走。启动后，在超级工厂桌面窗口中操作。

示例工程包 SuperFactory-2.0.1-Example-Factory.zip 是可选下载项。它提供已经建好的工厂与运行记录，需要通过超级工厂打开；使用软件内置模板则不需要下载这个包。

2. 启动页的三个入口

入口 适合谁 点击后怎么做
展示任务 想直接查看已有工厂和运行记录 先解压示例工程包，点击此入口，选择其中的“纸箱产运演示”目录，在预览中点击“确认打开”。
从模板开始 想用内置模板创建工厂并运行生产 首次使用先填写工程名称并点击“创建”，随后进入模板库，按下文步骤生成工厂。
空工程 想自己设计厂房和产线 填写工程名称并点击“创建”，再自行添加厂房、设备和生产方案。

第一次使用，建议选择“从模板开始”，完成一次“创建—运行—查看—保存”。想直接浏览已有成果，则选择“展示任务”。

刚启动、尚未打开任何工程时，也能使用“从模板开始”。它会先创建工程，再进入模板库。如果已有一个没有厂房和设备的空工程，这个入口会沿用当前工程，直接进入模板库。

顶部菜单里的“模块与模板库”是资源浏览入口。没有工程时可以查看模板，但要先创建工程，才能把模板中的厂房、设备和生产方案添加进来。

3. 先认识三个概念

名称 可以怎样理解
工程 保存工厂布局、设备、物料和生产方案的工作文件。
生产方案 本次准备生产什么、生产多少、何时供料，以及采用哪些任务和资源。
运行记录 按某一套输入计算出来的结果。以后修改方案，不会改写这次已经生成的记录。

二、基础操作：完成第一次生产仿真

1. 从空白启动创建模板工厂

  1. 在启动页点击“从模板开始”。
  2. 在“工程名称”中填写“我的纸包装工厂”，点击“创建”。名称也可以自行修改。
  3. 进入模板库后，选择“纸包装多产品工厂 · 92台设备”。
  4. 在右侧“配置模板工厂”区域，点击“使用模板演示配置”。软件会填入示例资源、原料质量、订单和检验设置。
  5. 手动填写“工厂前缀”，例如“演示工厂”。这个前缀用于区分本次创建的对象。
  6. 手动填写“方案名称”，例如“纸包装演示生产”。后续将通过这个名称选择生产方案。
  7. 点击“预览创建对象”。看到“创建预览”后，核对将添加的内容，再点击“创建模板工厂”。

创建完成后，模板库关闭，工厂出现在画布中，刚创建的生产方案会成为当前方案。填写了演示配置后，仍需手动填写工厂前缀和方案名称；只选中模板，也还没有把工厂添加到工程。

2. 查看工厂布局

画布上方可以切换“流水线画布”和“多厂房画布”。前者适合查看一座厂房内的设备与产线，后者适合查看多个厂房的分布；“画布厂房”下拉框用于切换当前厂房。

单击设备，或在左侧对象树中选择设备，可以在右侧查看属性。点击“工厂全景模式”可扩大观察区域，再点击“返回编辑布局”恢复工作台。

如果视角偏离工厂，点击底部“⌂ 复位视图”。面板被隐藏时，可通过“窗口”菜单重新显示，也可以点击“恢复默认布局”。

3. 运行生产方案

  1. 确认顶部“当前方案”已经选中刚创建的“纸包装演示生产”。
  2. 如需先查看订单，点击“2 配置订单”；查看完毕后点击“返回画布”。首次体验可以保留模板演示配置。
  3. 点击“3 运行方案”，等待底部处理状态结束。
  4. 运行完成后，通过“历史结果”选择这次记录，查看工厂中的设备作业与物料流转。

运行方案会计算生产结果；时间轴上的“播放回看”用于观看已经计算的过程。两者分开操作，播放回看不会重新发起一轮生产。

4. 回看生产过程和跟随物品

在底部时间轴中切换到“实际”，点击“播放回看”观看过程，点击“暂停回看”停在当前画面。可以调整“回看速度”，也可以在“观察毫秒”中输入具体时间后点击“读取时点”。例如，60秒对应60000毫秒。

点击时间轴中的“物品跟随”，在“跟随物品”中选择一条物品记录。面板会显示该物品在所选时点的持有位置、数量等信息；使用“此前事件”“后续事件”查看它的流转过程，使用“定位持有者”查找所在设备或位置。

如果希望三维画面跟着物品移动，在右侧物品记录中选中目标，再点击画布上的“跟随选中物品”。点击“全厂适配”可退出跟随并重新查看整个工厂。

想查看运输或成品形成的过程，应将观察时间移到相应作业发生的时段。在仿真的最后时点，已完成的设备可能处于空闲状态。

5. 查看产量与等待原因

点击“4 查看产量与等待”，查看所选运行记录中的交付情况和等待条件。核对结果时，请同时看订单需求、实际接受数量，以及对应的产品和单位。

在结果页核对订单交付数量。需要了解订单进度时，查看等待记录，定位原料、设备、运输和工序衔接的处理情况。

6. 保存工程，下一次继续使用

  1. 选择“文件 → 保存工程…”，在目录选择窗口中选定保存位置。
  2. 等待底部出现保存完成提示。
  3. 下次启动软件，选择“文件 → 打开工程目录…”，选中保存的工程目录。
  4. 在打开预览中点击“确认打开”，随后可继续查看布局、生产方案和已保存的运行记录。

保存工程是为了下次继续编辑；导出的报告主要用于阅读和分析，不能代替可编辑工程。关闭软件时如出现未保存或正在执行任务的提示，请按窗口提示完成保存或收尾。

7. 直接打开配套示例工厂

下载并解压示例工程包，找到内部的“纸箱产运演示”文件夹。启动软件后点击“展示任务”，或选择“文件 → 打开工程目录…”，选择这个文件夹，再点击“确认打开”。

请选中“纸箱产运演示”工程目录，不要选择应用程序目录，也不要选择压缩包的外层目录。打开后，可以浏览92台设备的工厂与本地运行记录。查看其中保存的云端产运记录，请按本指南第四部分操作。

三、进阶操作：调整、比较和整理工厂

1. 调整订单，再生成一次运行

建议先保存工程，保留一份便于返回的状态。然后按下面步骤尝试一次小范围调整：

  1. 点击“2 配置订单”，确认“当前方案”是要修改的方案。
  2. 在“任务与订单”分类中找到目标记录。记录较多时，可以使用“查找业务记录”。
  3. 修改需要调整的数量、优先级或时间字段，并按字段旁标注的单位填写。第一次建议只修改一个参数，方便理解结果变化。
  4. 点击“检查变更”，核对预览，再点击“确认应用草稿”。
  5. 点击“运行当前方案”，等待生成新的运行记录。
  6. 通过“历史结果”在前后两次记录之间切换，查看产量、等待和工序安排的变化。

在表单里输入新值后，还要确认应用，才会写入工程。已有运行记录仍保留当次使用的输入；修改方案后需要重新运行，才能得到新的结果。

2. 保留原方案，尝试另一套配置

在“业务输入”面板中选中原方案，点击“复制为新方案”。软件会选中带“（副本）”名称的新方案，并切换到方案设置。要调整订单，请在“业务面板分类”中点击“任务与订单”，再修改对应记录；调整供料或生产任务时，选择相应分类。

完成“检查变更 → 确认应用草稿”后，点击“运行当前方案”，生成副本方案的运行结果。

这样可以分别保留不同方案，避免来回修改同一份输入。用“当前方案”选择要编辑的配置，用“历史结果”选择要查看的运行结果。

3. 比较两次运行

  1. 至少完成两次运行后，打开“评审与交付 → 方案比较”。
  2. 在运行记录列表中选择两次记录，按界面中的“基准”和“候选”核对选择。
  3. 等待“正在读取所选运行记录…”提示消失，基准和候选内容加载完成，再点击已经可用的“比较所选两次运行”。
  4. 先看共同条件和可比性说明，再看产量、完工时间、等待和资源占用的差异。

例如，只调整某个订单的优先级后重跑，再与调整前比较，可以观察任务先后顺序是否变化。如果供料、数量或观察时长也同时变化，应结合这些差异理解结果。

整厂运行记录包含较多设备、物品和事件，首次读取需要等待。读取期间保留当前选择即可，不必反复勾选记录。

4. 从空工程练习厂房与设备布局

  1. 在启动页选择“空工程”，填写“空工程布局练习”并点击“创建”。
  2. 点击顶部“新建厂房”，名称填写“练习厂房”，宽度20米、进深12米、厂房净高6米，点击“应用到工程”。
  3. 打开“模块与模板库”，将“类别”切换为“设备”，在左侧选择“纸箱开箱机（RSC折底封底）”，点击“添加定义到工程”。
  4. 返回工作台后点击“添加设备”。名称填写“练习开箱机”，所属厂房选择“练习厂房”，设备定义选择刚添加的纸箱开箱机。
  5. 将X、Y、Z坐标分别填写为2、2、0米，绕Z旋转增量填写0度；矩形占地宽度、进深和设备包络高度均填写2米，点击“应用到工程”。这些尺寸用于本次布局练习。
  6. 设备出现在厂房中后，可按下一节练习移动、旋转和编组，最后保存工程。

完成布局后，可继续配置生产：依据所选设备要求，在“业务输入”中填写物料、工序、供料、资源和订单，使用“连接物料”建立交接。希望直接运行完整工厂时，请使用第二部分的模板流程，模板已准备好相应的生产输入。

5. 修改设备布局和整理线组

在画布上方点击“输入草稿”，再修改布局。选中设备，点击底部“↔ 移动手柄”或“⟳ 旋转手柄”，拖动对应手柄调整位置或朝向。需要按固定距离对齐时，启用“网格吸附”，填写合适的“网格步长”。

按住 Shift 或 Ctrl 单击可增减多选。选中多台设备后，点击“编组所选”，填写“新线组ID”和“线组名称”，再点击“应用编组”。选择线组后可整体调整；需要拆开时点击“解组”。

复制一组布局时，先选中设备或线组，再点击底部“复制为新ID”。在打开的复制面板中，为每个对象填写不重复的新ID和位移，最后点击该面板内的“复制为新ID”提交。复制后还要核对物料连接与生产任务，按需要配置新设备的业务用途。

“编辑”菜单中的“撤销”和“重做”可用于已支持的工程草稿操作。布局变化只作用于当前草稿；要评估调整后的生产表现，需要重新运行方案。

6. 检查草稿条件

点击底部“草稿检查”，选择产品、验收目的库位、观察时间范围和场地参照。根据需要填写场地条件，选择要检查的“引用与单位”“物料与过程连接”“场地、占地、高度和净距”，再点击“执行只读检查”。

使用本指南的模板练习时，可以按以下示例填写：

  • 行业：纸包装；产品族：纸滑套。这两项需要填写。
  • 产品修订：选择编号中包含 PF-PRODUCT-SLEEVE 的条目，对应纸滑套产品。
  • 验收目的库位：合格成品 · 八产品；验收阶段：卸货并放行。
  • 观察开始：0毫秒；观察结束：28800000毫秒，对应模板的8小时观察范围。
  • 场地参照：纸包装多产品演示厂房。

净距和静态区域应按自己的设计填写。留空表示没有提供这些条件，检查会保留相应缺项。

结果中的对象按钮可帮助定位问题。“无法确定”表示当前条件不足，先补齐对应输入再检查；修改工程或检查条件后，应重新执行。检查本身不会自动替你移动设备或修改生产数据。

检查后点击“返回画布”。如果提示检查表单尚未保存，可选择“明确放弃检查输入”关闭本次表单；这不会删除工厂或运行记录。选择“返回保留输入”则继续留在检查页。

7. 导出评估结果

  1. 点击“导出评估报告”，或打开“评审与交付 → 评估报告”。
  2. 选择要包含的运行记录；只导出一次运行时，选择一条即可。
  3. 选择“实际运行评估”，按用途勾选输出格式。HTML适合离线阅读，CSV适合表格分析，JSON适合后续程序处理，也可选择PDF。
  4. 点击“选择目录并生成报告”，等待界面出现“报告已生成”。打开刚才选择的目录，进入新生成的 evaluation-… 子文件夹，双击 index.html 阅读HTML报告。

请保留报告目录中的图像、工程和其他资源文件。完整工厂包含较多模型及运行数据，导出目录可能达到GB级，生成时也需要等待；任务仍在处理时，不要仅凭部分文件已经出现就关闭窗口。

软件中的等待明细每页显示100条，可用“上一页等待”“下一页等待”翻页；生成文件列表可展开查看并翻页。离线HTML报告的完整数据表在展开后分页显示，顶部筛选框搜索整张表的数据，不限于当前页。

尚未运行时，可选择“尚未运行的设计说明”，介绍当前工厂和方案。需要交给他人继续修改时，请同时保存、提供工程目录。

8. 调整模型精度，让整厂观察更流畅

在“视图”菜单中选择合适的显示档位：

档位 建议用途
简化 查看完整工厂、跟随生产过程，适合日常使用。
详细 近距离查看单台设备的外观和机构。
区域 重点查看厂房与设备分区，减少模型显示负担。
自动呈现档位 由软件根据当前观察情况调整显示档位。

整厂画面较慢时，可以先选择“简化”或“区域”。显示档位影响模型呈现，不会改变订单、产量或运行记录。

四、云端功能：回看记录与实时生产

1. 不连接云服务，回看示例记录

  1. 打开配套的“纸箱产运演示”工程。
  2. 点击“云端生产”，进入“执行”页。
  3. 在“生产记录”中选择“已保存记录1”。列表中会同时显示记录状态和时间。
  4. 向下滚动，点击“回看执行画布与时间轴”。
  5. 在执行观察页切换观察视角、厂房和模型精度；填写“观察时间（秒）”后点击“读取时点”，查看对应画面。
  6. 在“对象类别”中选择“运输记录”，点击具体记录，查看运输阶段与货物信息。

这里展示的是已经保存的执行历史，不会因为回看而重新启动生产。浏览这些记录无需云端连接文件。

2. 导入云端连接

实时生产和云端数据查询需要部署管理员提供连接文件，文件中包含对应环境的地址与访问配置。

打开工程并选择生产方案，进入“云端生产 → 设备”，点击“导入连接文件…”，选择管理员提供的文件。导入后保存工程，正常关闭并重新启动应用，再打开工程，检查连接和设备状态。

应用包本身不提供通用云账户。连接文件涉及访问权限，请按管理员约定保管，不要随示例工程或截图公开。

3. 准备并启动实时生产

  1. 在“设备”页确认本次设备有有效上报，并具备接单条件。
  2. 进入“执行”页，在“准备与运行生产”区域填写最终目标数量、目标单位、停止新派工时间和设备状态有效期。
  3. 选择本次需要的设备与阶段。初次操作建议使用较小的目标和已配置好的产线，便于核对结果。
  4. 点击“准备生产”。准备完成后，还需点击“启动”，系统才会分派任务。
  5. 查看多工序进度、产出和设备状态，再通过执行画布回看具体过程。

本地方案运行是生产仿真；云端执行记录来自所连接设备的上报。使用软件模拟设备时，记录反映模拟设备的执行情况。

4. 暂停、继续与正常收尾

操作 实际含义
暂停新派工 暂停分派新的任务，已经开始的工作继续收尾。
继续新派工 恢复后续任务分派。
停止新派工 停止后续派工，等待已经接纳的工作完成收尾。

需要操作时，先在“生产记录”中选择“当前会话”。历史记录和云端存档用于查看，不能控制当前设备。

切换页面不会停止生产。准备结束使用时，点击“停止新派工”，等待会话完成收尾，核对产出并保存工程，再正常退出。若仍有等待出料等未完成事项，先查看设备和执行记录中的提示。

5. 查询和导出云端数据

进入“云端生产”的“数据”页，选择数据集或所选生产记录，设置查询内容、时间范围及设备筛选，再点击“查询并固定结果”。

查询生产记录时，时间按准备生产后的经过秒数填写；点击“整段记录”可带入完整范围。按接收时间查询时，使用界面上的日期时间控件。查询结果的结束时点不计入范围。

结果较多时可以翻页。需要保存筛选结果时，点击“导出全部筛选结果”；需要整理整次生产时，在执行页点击“导出生产报告”。两种导出分别对应筛选数据和生产记录。

看到的情况 如何处理
点击“从模板开始”后先出现工程名称窗口 这是正常步骤。填写名称并点击“创建”，随后进入模板库。
Windows提示未知发布者 本版应用尚未进行Windows代码签名。先核对文件来自本指南所链接的正式下载页，再按系统或所在单位的安全策略确认运行。
模板能看见，但没有创建工厂的配置区 确认已经创建或打开工程；未打开工程时，模块与模板库只提供浏览。
使用演示配置后仍不能预览 检查“工厂前缀”和“方案名称”是否已经填写，并查看表单提示。
模板已经选中，画布仍然空白 完成“预览创建对象 → 创建模板工厂”，才会添加实际厂房和设备。
“运行方案”不可点击 确认“当前方案”已有选择，并等待当前处理任务结束。
工厂不在视野中，或面板不见了 点击“⌂ 复位视图”，或通过“窗口 → 恢复默认布局”恢复工作台。
