# 工程交接：打开、缺项、修改与继续

状态：设计规格，对应P2-03/P5-01。导出视频供观看；交接工程供另一人继续工作，二者不是同一成果。保留现有project/modules/results/views/说明结构，不另建在线项目服务。

平台还交付[PDF/HTML/CSV/JSON评估报告](评估报告与数据导出.md)，供审阅或分析；工程包供继续编辑和运行，类别模块包供社区复用。三个入口分别为“导出评估”“交付工程”“导出模块”，可同时交付，但不把报告截图当可编辑模型。

## 打开一份包要完成什么

|步骤|软件处理|接手者决定|
|---|---|---|
|读工程与说明|显示目标、接受位置、观察窗、声明/实际能力及所用版本|确认当前是设计包、实际运行结果还是可恢复快照|
|解析设备/规则|优先使用包内被工程明确引用的模块文件，不自动套本机最新版|缺定义时补正确版本或将受影响作业保留待配置|
|解析资产|区分行为、表现、专业输入与实际结果；列缺项影响对象|可明确替换缺照片/模型；不能用外观补出缺行为|
|查看原方案|旧输入和结果保持原归属，缺结果显示未执行|选择继续编辑、复现原输入或从支持快照续做|
|形成自己的方案|改配置/供给/路线/模块采用；列真正变化|明确采用，重新彩排后再写新结果|
|交回/贡献|只带允许再分发的实际所用资产与可编辑数据|决定交接或准备公开贡献，均不自动发送|

包内模块限定在本工程作用域，不覆盖接手者全局库。同id/version的本机模块与包内文件不同，不能悄悄替换；保存时仍指向实际采用文件。日后选全局升级走明确的实例采用流程。

## 哪些缺项允许继续，哪些影响结论

缺外观仍可保存/编辑并明确用内置示意替代，行为和库存不变；未替换时显示待补素材。缺必需行为/类型/端口/资源不能执行相关作业，画布保留布局和关联缺项，不能把未知设备当零秒机器。

缺价格只阻止相应成本结论，不阻止已有条件的时间彩排。缺专业计算结果时，已选calculated_nominal或software_in_loop的作业等待提供者；只有用户明确改为声明过程并新建方案，才能使用声明工时。没有自动降级。

只有设计包时不伪造results。只有旧结果而缺原配置/定义时，可以说明阅读范围，但不声明已能复现。整厂结果不能由只可运行的局部代替，报告列未建模/未运行范围。

## 相对路径与资产交接

导出把所用模块与可附素材收进包内，并重写包内相对引用；不把作者机器的绝对路径当作另一人能打开的文件。不附软件缓存、凭据、原始行业报告或无再分发许可文件。外部专业工具作为明确依赖和能力要求说明，不能假装已随包安装。

非可再分发照片/模型可以保留待替换位置和来源说明；显示替换会影响表现、包络还是专业条件。包中任意脚本不直接执行，入口检查格式、引用、能力和路径这些实际外部输入边界。没有增加校验和或第二份库存。

## 从头复现与条件快照续做

普通比较及首版交付从同一初始起点重跑是必做。完整运行快照续做只有软件明确支持且状态可恢复时才提供，不是无条件首版门槛；P2-03的release_acceptance据此验收。若用户明确选择已实际运行的某时点T继续，必须有完整可恢复状态：物品/容器当前持有、质量/分配、在制及有效进度、资源占用/车辆位置、已接受需求、未来事件、当前所用版本与专业状态。

继续保持原工程时间参考，start_at=T；T以前的到料/完成/领用不重放。已经接受的需求保留累计基数，新阶段另报增量；未发生的到料/日历/运输事件继续沿原绝对相对时点执行。不能把在途再变回来源，也不能重领已投入材料。

快照中已开始作业保留其原定义/版本和输入，直到完成或明确中止处置。采用新工时/BOM/模块默认只作用未开始工作，不能用新定义重新解释已有有效进度；要中止原任务必须按处置规则，不自动退料。示例原40秒任务已做20秒，即使后续任务改30秒，原任务仍剩20秒。

专业程序没有支持保存/恢复状态时，这个快照不能提供专业续做：允许读快照和从头新跑，不默默重启半个Job或将它当完成。只保存了截图、结果表或部分JSON不等于有可恢复快照。当前没有实际运行快照，样例只表达这些必要状态。

## 第三人接手演练

作者导出设计包→接手者在另一个目录打开→确认包内版本与缺项→修改一项工时/供货→保存为新方案→实际实现后同起点运行→重开并解释变化→交回可编辑包。设备、模块、视图和结果应继续指向相同对象。

本轮的文件构造/读取只能证明所列设计文件可携带和解析；P2-03须在实际软件验证打开/修改/保存/结果，P5-01再由第三人按说明完成演练。新目录读JSON不冒充上述软件接手通过。

目标生成工程交付包括目标、所选模板/模块版本、参数来源/缺项、布局连接及排期；工程可重新编辑。实际结果另带输入/方案/RunId，PDF/HTML/CSV/JSON评估不是工程快照。导入社区模板不带原作者运行库存，缺专业提供者保留缺项。
