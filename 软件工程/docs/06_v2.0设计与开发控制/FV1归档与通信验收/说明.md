### #7 修复后的本机复验

原版每次回看会再次取回完整 Run、重建工厂场景，保存还会同时保留多份未变的归档数据。修复后，同一已结束 Run 复用冻结输入，单个工厂画布只更新发生变化的内容。保存共享已经验证且内容相同的历史和模型；对顶点字节完全相同的简化模型只提交一次图形缓冲。工程格式与历史内容沿用原版本。

同一 H1 的固定 Run 在 600 秒内完成 55 次回看并返回。进程树从 4.42 GiB 到 4.84 GiB，增量 433.88 MiB。打开与回看的 10 分钟内峰值为 4.93 GiB，计入另存、正常退出和新进程重开后的实测峰值为 5.66 GiB。PF06 与 PF07 均通过。 [修复复验](历史回看修复复验.json) · [逐秒采样](修复候选本机内存采样.jsonl.gz)

主屏点击保存到成功提示 43.69 秒，新进程点击打开到生产记录可操作 11.82 秒。新进程读到 R15904。对保存文件独立解码得到 63,584 条历史，原工程 bundled 和 documents 下 7,654 个文件逐字节一致。保存后的首次关闭请求在 20 秒内未退出。确认没有未保存内容、活动任务或结清阻塞后，第二次正常关闭成功。

草稿、同一 Run、再返回草稿，画布在等待加载结束后分别装入 92/92、92/92、92/92 台设备。另从草稿 92 台模型全部实际加载后的独立起点观察 600 秒，增量 107.96 MiB。 [历史画面](历史回看主屏.png)

**复验步骤**

1. 在主屏正常启动候选，打开与基线相同的 H1 工程。选择已保存的历史 Run，等冻结输入出现，点击“输入草稿”返回，完成一次预热。
2. 在同一工程重复这两个动作，停留间隔最多 10 秒。在固定 600 秒窗口的首尾取临近的每秒 Private Bytes 样本。采样按进程创建时间和父子关系识别本次 Native 与 WebView2。
3. 确认草稿与 Run 的设备模型已经加载，另存到空目录。正常退出，用新进程打开刚保存的工程，进入“云端生产”，选择生产记录并核对最新修订。

## 隔离通信

A 选定 FV1 候选环境为独立 PostgreSQL 18、候选云服务和真实设备客户端，所有宿主端口限回环。测试了从冻结源码编译的 Windows Axum 服务，以及本机已有的 Sealos 仓库镜像，镜像摘要见[通信记录](communication.json)。项目生产数据库、线上应用均未参与。镜像复用实际 PostgreSQL 与分配给此轮的凭据和新数据库。PostgreSQL 与镜像同网络命名空间，容器中 PostgreSQL 地址为 127.0.0.1:5432，仅为该回环启用本地无 TLS 配置；远程数据库使用原 TLS 规则。

1. 按 `tools/cloud/local.py` 的组件环境准备独立数据库和私有权限文件，运行本提交云服务的迁移与 `acceptance.verify()`。已执行 111 项真实 HTTP/PG 检查。保留生成的组件数据库用于同一短链。
2. 只在该隔离环境挂载组件绑定配置并启动服务。宿主回环 23270 提供 HTTP 接口，健康检查须为 204。用 `python tools/cloud/fv1_short_chain.py send <私有目录> <本次唯一boot>` 发送 100 条固定观测。两个候选均用同一序列、路由、客户端与读回条件。
3. 停止该测试服务，运行同一脚本的 `disconnected`，再以原数据库启动服务并运行 `replay-read`。它重发同一序号的最后一个事件，逐页比对完整负载，确认 100 条各出现一次。需要恢复时停候选、以原摘要/配置和保留的测试数据库重启，重新检查 204、固定事件、命令及 Host 读取。结束后只停止该测试服务及数据库。
4. 在上述组件库上，给 `actual_fv1_short_chain_cloud_reads_in_host` 提供现行本地 Host 测试的 endpoint 与 scoped reader 环境，运行该 ignored 测试。真实 Host 的任务登记表返回目录、活动执行及固定 5 事件查询。百万条用例保持独立。另已验证过期探针不恢复派工及 32 项设备测试。

本轮短链功能通过。Linux 镜像的 SDK 入站 p95 约 30 ms，仅用于本机隔离短链决策。两候选的构建和操作系统不同，不据差值归因于传输层优化。现有结果不足以支持替换 SDK 网络层，保留原幂等和重试语义。主屏短流程已完成：真实 SDK 单次发送 37.21 毫秒，隔离数据库入站编号 302。用该次接收时间范围查询，实际 Host 返回唯一记录，逐项核对行内的设备启动标识和序号 1。点击到该行进入可视区域并经过两次浏览器帧回调为 233.5 毫秒，也是本次 Host 接纳查询至可见的上界。两段分开报告；手动发起查询，两段不相加。测试构建通过 fv1-reader-fixture 单独接入回环只读凭据，沿用普通 Host 任务、界面及渲染代码。[实测记录](主屏通信反馈.json) · [主屏画面](主屏通信反馈.png)。远端网络、93 端点到 UI 和 PF05 整厂计量归 FV3，届时先确认隔离云资源和余额。
