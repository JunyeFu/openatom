# 业务输入导航与修改

打开工程后，点击“2 配置订单”，进入“业务输入与方案”。

左侧按用途分成四组，点击组名可展开或收起：

|分组|主要用途|
|---|---|
|本次生产|核对任务与订单、方案与观察范围，查看实际接受与等待|
|产品与工艺|设置产品、用料、工艺路线、生产任务、设备角色与阶段参数|
|供料与资源|核对初始物品、后续到料、运输、人员、班次、物料预留与库位|
|质量与其他设置|设置质量、方案参数、成本与来源记录|

默认展开“本次生产”，全部原有分类仍可从这四组进入。左侧“已有N条”表示已经提供输入，不表示生产检查通过；“尚未提供”表示该类没有记录，不等于零值。提示“需先选择方案”时，先在顶部选择方案；尚无方案时点击“新建空白方案”。

修改现有记录时，在对应分类用“查找业务记录”按名称或完整编号查找，再选择记录。切换分组不会提交或丢弃表单；从其他页面定位对象时，对应分组会自动展开。

修改后按以下顺序操作：

1. 点击“检查变更”，核对预览中的修改内容。
2. 需要继续修改时，点击“返回继续编辑”；此操作不会应用变更。
3. 核对无误后，点击“确认应用草稿”。应用输入后，需要重新运行方案才会生成新运行记录，旧记录保留。
4. 通过工程的保存入口保存工程。应用业务输入与保存工程是两个步骤。

未应用的表单关闭时会提示保留或放弃；继续编辑请选择“返回保留表单”。组名和分类按钮可以用Tab定位、Enter操作；左侧分类和右侧内容可分别滚动。
