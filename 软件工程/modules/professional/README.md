# 专业计算模块

professional_contract声明输入、输出成果、单位/坐标、工具与支持范围。intended_modes是设计目标，available_modes是实际提供者能力，两者分开；缺提供者不能把声明工时当专业结果。

样例：[数控加工成果提供者](machining-producer/README.md)，尚无实际计算能力。完整41份方向保持[原专业工作](../../../模块研究/专业接入说明.md)，示例不是能力上限。成果、认可、消费者绑定和执行结果分开，工厂simulation才提交物品变化。协议见[九类清单](../../docs/03_架构与契约/九类模块清单与消费者.md)。
