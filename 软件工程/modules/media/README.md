# 表现素材模块
独立贡献插图、GIF和glTF/GLB。声明许可、来源、尺度/朝向/原点、适用设备、状态与动作映射。素材不携带生产规则；设备可替换素材而保留行为。无模型也能用图标彩排。待P3实现导入与预览。

新增图片序列及原生部件表现：时间轴引用包内图片资产或命名姿态，标签绑定声明数据／操作。可单独贡献图片对齐、阶段外观或原生部件；生产行为仍由设备包声明。Agent生成的数据与人工修改使用同一格式，许可声明不因生成方式而省略。

独立样例：[可编辑台面素材](editable-bench/README.md)。锚点使用input/output等角色，由采用它的设备显式映射到实际端口/读数，缺映射保留待补。更换素材不自动改变规划足迹、工时或数量。完整协议见[九类清单](../../docs/03_架构与契约/九类模块清单与消费者.md)，当前样例许可仍待发布前声明。
