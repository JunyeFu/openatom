SQLite有sources、claims、statistics、metrics四张表。可用SQL：
```sql
SELECT id,title,url FROM sources WHERE body LIKE '%物流%';
SELECT id,claim,metadata FROM claims;
```
统计表按行业名去重；网页中重复展示的表格不重复计数。来源记录数不是独立客户案例数或文献样本量。

## 保存与发布
原始资料仅在本机研究保存，不随开源软件整体再分发；公开作品使用原始网址、自行总结及可合理引用的数据，素材/代码授权分别核对。网页快照不是离线镜像，外部图片及脚本不保证存在。自建AI预览与本次文献原文分开。

当前阅读结果不会自动证明用户采用、节省工时、现场准确性或商业收入。需要的下一层证据见尚待取得清单。
