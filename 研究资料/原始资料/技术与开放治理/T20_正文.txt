JaamSim Release Notes 2 July 6, 2026 
Change Log 
Changes in release 2026-05: 
• Redo/Repeat button.  The Redo button has been modified to include the 'repeat' function using the same 
conventions at Microsoft Word and Excel.  When a new object is selected, the repeat button executes the 
last command for the new object, if it is applicable.  Keyboard shortcuts for 'repeat' are Ctrl+Y and F4. 
• 'FractionCompleted' output for EntityConveyor.  This output returns the fractional distance travelled by 
each entity on the conveyor. 
• 'TriggerPointList' input for EntityConveyor.  This input specifies one or more fractional distances along 
the conveyor at which the conveyor will notify any object that includes the conveyor in its 'WatchList' 
input.  Any entity that reaches a trigger point will cause the watchers to be notified.  
• 'EntityConveyor Example – with TriggerPointList' model.  The example model demonstrates the use of 
the TriggerPointList input. 
• Example models re-organised into a tree structure.  This example models have been re-organised into a 
tree structure with the same headings as the Model Builder, e.g. Graphics Objects, Probability 
Distributions, etc. 
Changes in release 2026-04: 
• 'ServiceDuration', 'ServicePerformed', and 'FractionCompleted' outputs for EntityProcessor.  These 
outputs are provided to make the EntityProcessor object consistent with the Server object.  Note, 
however, that for an EntityProcessor these outputs return an array of values (one for each entity being 
processed) instead of a single value. 
• Option to delete an unused DisplayModel.  Two objects are created when an image file or 3d file is 
imported: 1) a DisplayModel that holds the graphics data, and 2) a DisplayEntity that appears in the 
model.  The DisplayModel is an ImageModel in the case image file and a ColladaModel in the case of a 3d 
file.  If the imported DisplayEntity is deleted, it is easy to forget to delete the DisplayModel that 
references the file.  To avoid a model becoming cluttered with unused DisplayModels, the user is now 
prompted to delete a DisplayModel that becomes unused when the only DisplayEntity that references it is 
deleted. 
• 'ScriptedViewDirection' input for View.  This input replaces the 'ScriptedViewCenter' input to be 
consistent with the 'ViewDirection' input that was introduced in release 2026-03. 
• 'UserList' output for DisplayModel.  This output lists all the objects that use this DisplayModel for their 
graphical display. 
• Bug fix for model execution on multiple threads.  The ability to run models on multiple threads has been 
restored.  This feature was broken accidentally in release 2026-01. 
• Bug fix for file streams.  Connections to input and output files are closed correctly when an error occurs.  
Changes in release 2026-03: 
• Point-of-Interest.  Zooming and orbiting actions with the mouse are centred on the point -of-interest in 3d 
space.  The rules for setting this location have been refined to improve user experience.  It is now set 
when an object is dragged-and-dropped, when it is dragged to a new position, and when it is right- or left-
clicked.  The point-of-interest is unchanged by a right- or left-click when no object is under the cursor.  
However, when the coordinate grid is visible, the 'XY-Grid' object provides an object on the xy-plane to be 
detected by a mouse click.  Formerly, the point-of-interest would be set by default to the point on the xy -
plane that was under the cursor when no object was present.  For 3d models located far from the xy-

• 'XY-Grid' object.  This existing object, which displays the coordinate grid on the xy-plane, has been 
changed to use a ShapeModel instead of a ColladaModel to provide its graphics.  A new 'GRID' option has 
been added to the 'Shape' input for ShapeModel for this purpose.  A new feature is that the background 
colour and transparency for the XY-Grid object can be set using the FillColour input for the 'Grid100x100'

not visible, but is detected by a mouse click.  Models created with earlier versions of JaamSim can still be 
loaded into this version. 
• 'ViewDirection' input.  This input for the View object sets the direction of its camera.  Formerly, the 
'ViewCenter' input was used for this purpose.  Models created with earlier versions of JaamSim can still be 
loaded into this version. 
• Astronomical distances.  The 3d graphics code has been refined to work correctly for the enormous 
distances required by astronomical models.  Objects separated by a distance of up to 100 billion light-
years can be displayed together. 
• Internal improvements.  The code for view cameras and rendering has been streamlined. 
Changes in release 2026-02: 
• Optimisations for Java 25.  The software has been optimised for use with the Java 25 virtual machine.  
Some users may see a performance improvement.  The software is still backwards compatible with the 
Java 8 virtual machine. 
• Internal improvements.  Cleanups have been performed to simplify and improve window handling. 
Changes in release 2026-01: 
• Outputs for Model Inputs.  All model inputs now have a corresponding output that displays its current 
value and that can be used in an expression.  Previously, only a limited number of inputs had a 
corresponding output, and in some cases, they did not work correctly in an expression. 
• 'Parent' input for all objects.  The Parent input allows the user to designate an object to be the child of 
another object.  When an object is cloned or copied, all its child objects are clone or copied along with the 
parent.  One use for this feature is to display additional information for the clones created by an 
EntityGenerator. 
• 'Set Parent and RelativeEntity' menu item.  The context menu (right-click) now includes an entry for 
setting the Parent and RelativeEntity inputs.  In most cases, the position for a child entity should be 
relative to its parent. 
• Drag-and-drop for all objects.  Any object that has a child entity or a clone will appear in the Model 
Builder under the heading 'User-Defined Objects'.  SubModels are automatically included by this 
condition.  When dragged and dropped, a user-defined object creates a clone.. 
• 'Paste Clone' menu item.  The context menu now includes an entry for 'Paste Clone' that will insert a 
clone of a copied object.  By creating a clone, the original object will be added automatically to the Model 
Builder under 'User-Defined Objects', making it easier to create additional clones. 
• 'SimShape' object added to Process Flow library.  The SimShape object is a 2D version of SimEntity that is 
based on the Shape object and includes additional inputs for Filled, FillColour, Outlined, LineColour, and 
LineWidth.

JaamSim Release Notes 4 July 6, 2026 
• 'Job Shop Example' model.  This example model under Help > Examples is based on the problem 
described in Chapter 2.7 of “Simulation Modeling and Analysis”, 5 th Edition, by Averill M. Law.  The model 
demonstrates the use of SubModel, SimShape, and child entities.  
• 'Image' object added to Graphical Objects library.  This object has been added to make it easier for users 
to learn how to add images to their models.  Formerly, it was necessary to use a DisplayEntity for this 
purpose. 
• 'PixelSize' output for ImageModel.  This output returns the width and height of the image in pixels. 
• 'AlignEntities' input for EntityConveyor.  The default setting of FALSE for this input allows an 
accumulating conveyor to use the same positioning of conveyed entities as a non -accumulating conveyor.  
It should be set to TRUE for an accumulating conveyor that conveys entities with different lengths.  
• 'EntityConveyor Example - with Entities of Different Length' model.  This example model under Help > 
Examples shows how to use an accumulating conveyor when the conveyed entities that have different 
lengths. 
• 'WatchList' input for EntityConveyor.  This input allows a change to the TravelTime input to be recognised 
by an EntityConveyor when one of the objects in the list changes state.  Otherwise, a change in the 
TravelTime input is recognised by the arrival or exit of an entity.  A WatchList entry should be provided 
whenever an expression is entered to the TravelTime input.  Otherwise, the TravelTime expression will 
tested at each event time (i.e. a conditional event) to determine whether or not its present value has 
changed. 
• 'PresentTravelTime' output for EntityConveyor.  This output returns the travel time that is being used at 
present for the conveyor.  This time can differ from the value for the TravelTime input if the conveyor has 
not been updated by the arrival or exit of an entity, or been triggered by an entry in its WatchList.  
• 'ServerAndQueue' object removed from the Model Builder.  This object is no longer available for 
dragging and dropping into a model.  For backwards compatibility, it is still available for use in existing 
models. 
• Updated 'Nested SubModel Example' model.  This example model under Help > Examples has been 
updated to use a SubModel instead of the ServerAndQueue object, which is no longer available.  
• 'RelativeEntity' input accepts an expression.  The RelativeEntity input can now accept an expression that 
returns an entity. 
• 'Name' and 'Parent' inputs locked for Simulation.  It is not possible to change the name or parent for the 
Simulation object. 
• Default 'Parent' input set to null.  Previously, the default Parent was the Simulation object. 
• 'NumberDestroyed' output for EntitySink.  Returns the total number of entities that have been destroyed 
by the EntitySink including those during the initialisation period (warm -up).  This output is analogous to 
the 'NumberGenerated' output for EntityGenerator.  These two outputs allow the number of entities in 
progress (i.e. the work in progress) to be calculated. 
• Speedup for EntityProcessor with variable capacity.  If its Capacity input is an expression, an 
EntityProcessor checks whether its present capacity value has changed  at each event time (i.e. a 
conditional event).  However, if a WatchList input is provided, the capacity is now checked only when 
triggered by a state change to the objects in the WatchList, which is much more efficient.  
• Expression format used for numerical outputs.  All numerical outputs are now displayed in expression 
format to help make it clear that they can be used in expressions.  
• Bug fix for 'Show Labels'.  An error message is generated if the user attempts delete an EntityLabel while 
the 'Show Labels' button is turned on.  Formerly, the label would be deleted successfully, but it would be 
restored by the 'Show Labels' button if the model was restarted or if it was saved and reloaded.

JaamSim Release Notes 5 July 6, 2026 
• Bug fix for Attributes.  Attribute values are returned with the correct unit type prior to the start of a 
model.  Formerly, the unit type was unassigned after a model had been loaded but not started.  
• Bug fix for copying a SubModel.  Fixes a bug that occurred when a SubModel was copied with the 'Show 
Labels' button turned off. 
• Bug fix for a SubModel label.  Fixes a bug that caused the EntityLabel for a SubModel to disappear when 
the 'Show SubModels' button was turned off. 
• Bug fix for deleting a SubModel.  A SubModel with clones can now be deleted and restored successfully.  
Changes in release 2025-10: 
• 'EntityDependentList' output.  This output returns a list of the objects whose inputs reference the 
present object. 
• Bug fix for 'EntityReferenceList' output.  This output now includes any objects that are included in the 
'AttributeDefinitionList' input. 
• Bug fix for 'NumberRequired' input.  This input for the Assemble and Combine objects can now accept 
expressions that use the 'obj' output. 
• Bug fix for window size.  A bug has been fixed that caused the Control Panel window to be occasionally 
shown as a small square when the software is first launched. 
• Bug fix for View window position.  A bug has been fixed that frequently caused the View window to be 
displaced slightly from its normal position when the software is first launched.  
• Bug fix for error handling.  A second stack trace has been removed from the software output that was 
caused by a null-pointer exception that occurred during the handling of a runtime error . 
Changes in release 2025-09: 
• Internal changes.  Changes have been made to the JaamSim code to resolve some software design issues.  
These should not affect the user experience. 
Changes in release 2025-08: 
• ‘FractionCompleted’ output for Process Flow objects.  In addition to Server and EntityGenerator, which 
already have this output, the ‘FractionCompleted’ output is now available for:  Assemble, Combine, 
AddTo, Pack, RemoveFrom, Unpack, and EntityGate. 
• ‘simTimeForDate’ function.  This function calculates the simulation time that corresponds to a specified 
calendar date. 
• 'Monthly Totals Example' model.  This example model under Help > Examples shows how the 
‘simTimeForDate’ function can be used to collect operating statistics at the start of each calendar month.  
• JOGL 2.6.0.  The JOGL software that provides the OpenGL support for 3d graphics in JaamSim has been 
updated to the latest release.  It should have no effect on JaamSim.  Please report any anomalous 
behaviour to the JaamSim forum. 
• Bug fix for XYGraph.  A bar graph created using the XYGraph object can now display a single bar.  
Previously, nothing was shown until there were two or more bars to display. 
• Bug fix for Run Progress.  The Run Progress display is now shown with a progress bar for each thread as 
soon as the Play button is pressed.  Previously, due to a bug introduced accidentally in release 2025 -06, 
the progress bars for each thread were shown only after all threads had been started.

JaamSim Release Notes 6 July 6, 2026 
Changes in release 2025-07: 
• Increased range for ‘Speed Multiplier’ input.  The upper limit for the ‘Speed Multiplier’ input has been 
increased from 1 million to 100 million.  The new limit is equivalent to 3.2 years of simulated time per 
second of real time.  To increase readability, the display now includes comma separators for thousands, 
millions, etc. 
• Bug fix for EntityConveyor.  A non-accumulating EntityConveyor now displays the entities being 
transported in their correct positions when the conveyor is included in a sub-model or whose 
‘RelativeEntity’ input has been set.  A bug introduced in release 2025 -05 caused the entities to be 
displaced from their correct positions. 
• Bug fix for auto-complete menu.  The entries in the auto-complete menu for outputs in the Input Builder 
are now shown in the correct order.  Previously, the entries for attributes and custom outputs were 
displayed in order of definition. 
• Bug fix for Input Editor.  The scroll position for the Input Editor is now retained when a new object is 
selected for editing.  Previously, the highlighted keyword would be scrolled to the top of the editor. 
• Bug fix for ‘AttributeDefinitionList’ input.  An ‘AttributeDefinitionList’ input that is set before the 
‘RecordEdits’ in the configuration file is now handled correctly.  A bug introduced in release 2025 -05 
caused this input to become corrupted if the model was saved after any other input for the object in 
question was edited. 
• Bug fix for window title.  The default window title is now “Model1 - JaamSim”.  A bug introduced in 
release 2025-06 set the title to a blank string. 
• Bug fix for ‘Remaining Time’ and related displays.  The displays for ‘Remaining Time’, ‘Run Progress’, and 
‘Achieved Speed Multiplier’ are now retained when the simulation run is paused.  A bug introduced in 
release 2025-06 caused them to be cleared. 
Changes in release 2025-06: 
• Bug fix for 'AttributeDefinitionList' input.  The expression that is used to set the initial value for an 
attribute can now reference the attributes and/or custom outputs for other objects.  Previously, 
attributes could be defined in this way, but the saved configuration file would not load correctly.  
Furthermore, execution on multiple threads would cause similar problems.  
• Bug fix for window sizes.  Tool and view window sizes are set more reliably to their default values on 
startup.  On occasion, there would sometimes be gaps between windows on launching JaamSim or the 
software would launch with the windows minimized. 
• Bug fix for Big Lean Library examples under Java 8.  A bug has been corrected that prevented the Big 
Lean Simulation Library examples from working correctly under Java 8 when accessed through Help > 
Examples. 
Changes in release 2025-05: 
• Big Lean Simulation Library.  The simulation models for lean manufacturing created by Jerry Levasseur 
have been added as example models under Help > Examples.  The accompanying videos have been added 
to the JaamSim YouTube channel for easy access. 
• Example model files.  Some of the example models under Help > Examples require an additional input file 
to be processed.  The example models for FileToVector, FileToMatrix, and FileToHashMap are the ones 
most commonly encountered.  When one of these models is opened by the user and then saved as a local 
copy, the user is prompted to save a local copy of any additional files.

JaamSim Release Notes 7 July 6, 2026 
• Auto-complete menus for Input Builder.  The auto-complete menu for functions has been modified to 
ignore the space bar.  For the other two auto-complete menus (outputs and objects), pressing the space 
bar accepts the present menu entry.  This change was made to allow the user to continue typing when the 
auto-complete menu for functions is not needed, which is often the case. 
• Bug fix for ‘2D View’ button.  This button is now disabled when the ‘Movable’ input for the present view 
has been set to FALSE. 
• Bug fix for EntityConveyor.  When accumulating conveyors were introduced in release 2023-02, the 
positions of the entities on the conveyor were changed to align their left-side instead of their centre.  This 
change was needed for the spacing between entities to be correct.  However, it causes non -accumulating 
conveyors to have some undesirable consequences, particularly when the conveyor travels in the y -
direction.  For this reason, non-accumulating conveyors have been changed back to their original logic . 
• Bug fix for SubModel.  A bug has been fixed that caused the components of a SubModel clone to inherit 
the wrong value for its Region input.  This error was introduced accidentally in release 2024 -08. 
• Bug fix for ‘CloneList’ output.  When a model was executed in headless mode, the CloneList output failed 
to include any clones created by an EntityGenerator. 
• Bug fix for Images.  An Image now appears correctly when its ‘Orientation’ input rotates it out of the xy-
plane.  Previously, an image would become increasingly dark as the angle from the xy -plane was 
increased.  It became completely black when the image was vertical.  This bug affected the appearance of 
any model icon that was rotated out of the xy-plane. 
Changes in release 2025-04: 
• Bug fix for Event Processing.  A bug has been fixed that caused some models to freeze in the middle of a 
run, with the error message “Spurious wakeup in EventManager eventStack.Thread[processthread -
1,6,main]” printed to System.out.  The bug was introduced accidentally in release 2025-02. 
Changes in release 2025-03: 
• Bug fix for Real Time.  A bug has been fixed that caused some models to run excessively slowly when the 
‘Real Time’ button was selected.  The bug was introduced accidentally in release 2025 -02. 
Changes in release 2025-02: 
• Event Viewer cleanup.  When a model is started, the Event Viewer now shows only the ‘startUp’ events 
for the objects that have been defined by the model.  Formerly, a very large number of unnecessary 
startUp events would be executed for pre-defined objects such as Units and DisplayModels that do not 
need to be started in this way. 
• EntityProcessor statistics.  The EntityProcessor object now has a complete set of outputs such as 
“UnitsInUseAverage” that are analogous to those for the Resource object. 
• Error checking for AddTo, RemoveFrom, and Unpack.  These objects now check that an EntityContainer 
or related object is received from the ‘WaitQueue’ for the RemoveFrom and Unpack objects, and from the 
‘ContainerQueue’ for the AddTo object.  Formerly, this type of error would result in an unhelpful Java 
error message. 
Changes in release 2025-01: 
• Auto-complete menu in Input Builder.  An auto-complete menu is cleared when a user presses the 
Escape key or clicks anywhere in the input field.

JaamSim Release Notes 8 July 6, 2026 
• “PRESENT VALUE” display in Input Builder.  For the ‘CustomOutputList’ and ‘AttributeDefinitionList’ 
inputs, the PRESENT VALUE display now shows the present value for each of the custom outputs and 
attributes that were defined. 
• ExpressionStatistics inputs and outputs.  The ‘TargetPercentiles’ input and a number of outputs were 
added to ExpressionStatistics to make it consistent with the Statistics object.  
• ‘Cursor Position’ popup.  The popup description for the Cursor Position display has been corrected to 
refer to a position in 3D space. 
• Custom Output Report.  The blank line between scenarios has been removed when only one replication is 
performed. 
• Bug fix for View windows.  A bug has been fixed that sometimes caused a view window to rotate 
randomly by 90 or 180 degrees while it is dragged in the x-y plane.  This bug first appeared in release 
2024-04. 
• Output Viewer displays error message.  When a custom output cannot be evaluated, the relevant error 
message is now displayed in the Output Viewer.  Formerly, the text “Cannot evaluate” was displayed.  
• Improve error message for cfg file problems.  A common error in a cfg file that has been edited manually 
is to forget to include a closing brace (‘}’) or a closing single quote mark (‘).  When this occurs, the input 
parser reads to the end of the file and prints an error message that appears at the end of the .log file.  The 
error message now prints the first line in file that could not be parsed, which makes it much easier to 
locate the missing closing brace or single quote mark. 
Changes in release 2024-09: 
• Auto-complete feature for Input Builder.  A new auto-complete feature for function names and special 
names such as ‘this’, ‘simTime’, ‘sub’, etc. have been added to the Input Builder.  This feature 
complements the auto-complete features for entity names and output names. 
• Documentation pop-ups for Input Builder.  Documentation pop-ups now appear in the Input Builder 
when the mouse is positioned over each part of an expression.  For example, if the mouse is positioned 
over the ‘size’ function, then a pop-up appears that describes this function, including its inputs, outputs, 
and examples of its use. 
• Functions ‘discrete’ and ‘continuous’.  These functions randomly select from user-defined discrete and 
continuous distributions respectively.  They are analogous to the DiscreteDistribution and 
ContinuousDistribution objects in the Probability Distributions library.  
Changes in release 2024-08: 
• Resources seized by a DowntimeEntity.  Inputs ‘ResourceList’ and ‘NumberOfUnits’ have been added to 
DowntimeEntity to specify the resources that must be seized before the ‘repair’ activity for the downtime 
event can begin.  The resources are released when the repair activity is finished and the DowntimeEntity 
resumes its ‘Working’ state.  If the specified resources are not available to be seized, then the 
DowntimeEntity is set to the state ‘WaitingForResources’ and work is halted.   This feature could be used, 
for example, to model a limited number of maintenance workers that perform the planned and 
unplanned maintenance for a number of processes.  An example model 'DowntimeEntity Example - with 
ResourceList' has been added under Help > Examples to illustrate the use of this feature.  
• Entity reference arrows.  When the ‘Show References’ button is selected, the reference arrows now point 
from the centre of the first object to centre of the second object.  Previously, arrows pointed to/from the 
‘Position’ input values, which is not always the centre of each object.  Furthermore, a small dot has been 
added at the beginning of each arrow.

JaamSim Release Notes 9 July 6, 2026 
• Undo for SubModel deletion.  A single entry is now shown in the ‘Undo’ button’s list when a SubModel is 
deleted.  Formerly, each of the SubModel’s components had a separate entry in the list. 
• Bug fix for output reports.  The ‘RunDuration’ and ‘InitializationDuration’ outputs are now recorded in the 
.rep and .log reports in the same way that they appeared with releases of the software prior to 2024 -07. 
• Bug fixes for EntityLabel.  The EntityLabel is now hidden for an entity that has exited the model and been 
added to a pool for re-use. 
• Bug fix for selected entity.  The entity selected for display in the Input Editor and Output Viewer is cleared 
when the entity exits the model. 
Changes in release 2024-07: 
• EntityLabel recast as a child of its target object.  Instead of naming the EntityLabel for an object by 
appending “_Label” to the object’s name, it is now simply a child of the object.  For example, the 
EntityLabel for the object [Server1] is now the child object [Server1.Label] instead of being a separate 
object named [Server1_Label]. 
• Bug fix for line width.  Lines with a width of zero pixels are now shown as invisible.  Formerly, most 
computers displayed a line with zero width in the same way as one with a width of 1 pixel.  However, on 
some computers, a zero-width line would cause the view windows to stop working. 
• Bug fix for EntityLabel positions and formats in a SubModel clone.  The position and format of an 
EntityLabel in a SubModel clone are now synchronized with the position and size of the EntityLabel in the 
prototype SubModel. 
• Bug fix for model inputs as outputs.  Name collisions between existing outputs and the new ones that 
echo an input value have been resolved. 
• Bug fix for Object Selector.  The Object Selector is updated correctly when a generated entity is re-cycled 
by an EntityGenerator. 
• Bug fix for EntityLabel.  Entity labels are shown correctly when a new model is opened.  
• Bug fix for saved and imported SubModels.  A SubModel is now saved in such a way to avoid errors 
involving its Region. 
• Bug fix for window positions.  A bug has been fixed that occasionally caused the tool and view windows 
to be incorrectly sized and positioned when a model is opened. 
Changes in release 2024-06: 
• Model inputs as outputs.  Most of the inputs to each simulation object are now available as outputs, and 
can be used in expressions.  These new outputs appear at the bottom of the Output Viewer.  
• Inputs to SubModel clones.  All inputs to the components of a SubModel clone can now be overridden in 
the Input Editor.  Formerly, inputs that referenced the parent SubModel were show in grey and could not 
be overridden. 
• EntityLabel shows the local name.  To reduce clutter, an EntityLabel now shows its entity's local name 
instead of its global name.  For example, the global name of Server1 contained in SubModel1 is 
'SubModel1.Server1', whereas its local name is 'Server1'. 
• 'Name' input.  All objects now have a 'Name' keyword which can be used to change the object's local 
name.  This method is more convenient for renaming an object than using the Object Selector or the 
EntityLabel.  Note that only the local name can be changed for an object. 
• Control Panel size.  The main window for JaamSim is now fixed in size and its 'maximize' button has been 
disabled.

JaamSim Release Notes 10 July 6, 2026 
• 'Lock Windows' button.  This new button in the button bar allows the user to prevent the tool and view 
windows from being re-positioned or re-sized accidentally. 
• 'NumberStarted' and 'NumberCompleted' outputs.  These new outputs for DowntimeEntity return the 
number of downtime events that have been started and completed up to the present time.  
• 'Children' output.  This output lists the objects that are subordinate to the present object.  For the case of 
a SubModel, these objects are its components. 
• Bug fix for window sizes.  A bug has been corrected that prevented the position and size of the tool 
windows from being preserved between the saving and relaunching of JaamSim.   The bug was introduced 
accidentally in release 2020-03. 
Changes in release 2024-05: 
• Pixel scaling.  High resolution monitors that use pixel scaling are now supported natively.  The 'Display 
Menu' app is no longer required for Mac computers with a Retina monitor.  
• Improvements to the Finder tool.  A list of objects copied to the Finder now generates a menu entry for 
each object in the list. 
• Context menus for Input Editor and Output Viewer.  These windows now provide a context menu when 
the selected row is right-clicked.  For the Input Editor, the options are Cut, Copy, Paste, Delete, and Find.  
For the Output Viewer, the options are Copy and Find. 
• Faster startup for complex models.  Models with many SubModels that contain large numbers of objects 
now start executing after only a short delay.  Formerly, these models could take several minutes before 
simulated time began to advance. 
• Improved error messages.  Minor improvements to the formatting of error messages. 
• Bug fix to the use of 'this' in expressions.  This bug affected expression inputs that included 'this' for 
ExpressionEntity, InputValue, Polynomial, SineWave, SquareWave, and WeightedSum . 
Changes in release 2024-04:

• Object orientation by prototype and clone.  A ‘clone’ is an entity that inherits all its input values from

array and returns an array with the resulting values.  For example, map(|x|(2*x), {1, 2}) returns {2, 4}. 
• Filter function.  A higher-order function that applies a one-input lambda function to each element of an 
array and returns an array with only the ones that return TRUE (i.e. a non -zero number).  For example, 
filter(|x|(x>2), {1, 2, 3, 4}) returns {3, 4}. 
• Reduce function.  A higher-order function that applies the first input of a two-input lambda function to 
each element of an array.  The second input to the reduce function is the initial value to be assigned to an 
internal value maintained by the function during the calculation.  The result of the calculation for each 
element is assigned to this internal value.  After the last element is processed, the internal value is 
returned.  The reduce function has three inputs: the function, the initial value to be assigned to the 
internal value, and the array to be processed.  For example, reduce(|x, accum|(x + accum), 0, {1,2,3}) 
returns 6.
