## TF-00 实际编译和运行

在系统临时目录写入以下自有、无第三方依赖的源文件；没有写入产品目录或建立Cargo项目：

```rust
fn main() { println!("native_toolchain_smoke_ok"); }
```

执行现有工具链：`rustup run stable-x86_64-pc-windows-msvc rustc <main.rs> -o <native-smoke.exe>`，随后运行产物。编译/链接退出码0，运行退出码0，stdout为`native_toolchain_smoke_ok`。没有安装、下载或启动服务。

这是Windows原生基础编译/链接/运行的局部证明；不包含Tauri、React、Three.js、MCP、Parry、printpdf或产品业务，不能将任何P任务填done，不能计3厂房/60设备/3000件运行通过。TF-01—TF-06实际结果仍未取得；原可行性证明evidence_credit=0保持。
